
# UGM_Calculator

## About the Project
UGM_Calculator is a group project developed by 10 Computing students. Our goal is to build a simple, user-friendly calculator while learning Python, software development and teamwork.

## Project Features
- Addition, subtraction, multiplication and division
- Clear and backspace buttons
- Error handling, including division by zero
- Simple graphical user interface (GUI)
- Calculation history 

## Technologies
- Python
- Flask 
- HTML, CSS and JavaScript 
- Git and GitHub
- Tool for UI design

## Project Structure
- `backend/` — Python code and calculation logic
- `frontend/` — User interface
- `tests/` — Tests
- `docs/` — Project documentation

## Team Collaboration
We use GitHub Issues to organise tasks, GitHub Projects to track progress, and Pull Requests to review changes before merging them into the main branch.
